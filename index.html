Kapwa Design System

A high-performance, accessible, framework-agnostic design system built for Philippine public services, enterprise operations, and digital portals. Engineered in pure HTML, CSS, JavaScript, and Python — no TSX, TypeScript, or heavy bundlers required.

Design Values (Kapwa Ethos)

Rooted in BetterGov.ph Community Guidelines

1. Malasakit (Compassion)

Designed for real human needs. Interfaces must be accessible, high-contrast, effortless to navigate, and reliable on low-bandwidth networks.

2. Bayanihan (Collaboration)

Standardized components shared across civic organizations and private enterprise, lowering development friction and elevating user trust.

3. Universal Clarity

Zero dependency lock-in. Clean HTML/CSS/JS/Python accessible to all developers regardless of whether they use React, Vue, Django, Flask, or plain static HTML.
